# 曾国藩研究体系

我其实不是单纯想读一个历史人物，而是在寻找一个问题：

> **一个普通人，如何通过长期修身、学习、做事、识人、用人和自我管理，逐渐形成强大的现实能力？**

那么可以把曾国藩拆成六个模块：

| 模块     | 主要问题               | 推荐材料            |
| ------ | ------------------ | --------------- |
| **修身** | 他如何改变自己？           | 《曾国藩日记》         |
| **做人** | 他如何处理人与人的关系？       | 《曾国藩家书》     |
| **做事** | 他如何解决复杂问题？         | 《曾国藩奏折》         |
| **用人** | 他如何识人、培养人、组织人？     | 家书＋奏折＋传记        |
| **处世** | 他如何处理权力、利益、名誉与进退？  | 日记＋家书           |
| **思想** | 他为什么这样做？他的价值观从何而来？ | 《曾国藩文集》＋《求阙斋日记》 |

阅读顺序：
1. 先读张宏杰《曾国藩传》——建立框架
2. 《修身之道：唐浩明评点曾国藩日记》——修身
3. 《唐浩明评点曾国藩家书》——做人
4. 《唐浩明评点曾国藩奏折》——做事
